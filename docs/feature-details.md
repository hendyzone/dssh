# dssh 功能细节清单

> 逐模块、逐交互点的细化需求。✅ 已实现 / ❌ 缺失 / ⚠️ 已实现但有缺陷。
> 状态基于 v0.2.2 代码实际盘点（apps/desktop），不是凭印象。
> 优先级标注：🔴 影响日常使用的缺陷、🟡 体验补齐、🔵 锦上添花。

## 1. 标签页栏（App.tsx tab-bar）

| 功能点 | 状态 | 细节 |
| --- | --- | --- |
| 点击切换 / 按钮关闭 | ✅ | — |
| 同服务器多标签 `#n` 序号 | ✅ | 自动区分 |
| **重命名标签页** | ❌ 🔴 | 双击标签名进入行内编辑，回车确认 / Esc 取消；自定义名后不再跟随服务器名与 `#n` 序号 |
| 中键关闭标签 | ❌ 🟡 | 浏览器惯例 |
| 拖拽调整标签顺序 | ❌ 🟡 | |
| 标签右键菜单 | ❌ 🟡 | 重命名 / 复制此会话 / 关闭其他 / 关闭右侧 |
| 关闭前确认 | ❌ 🔴 | 会话仍连接时关标签（或关窗口）需确认，防误关。当前点 × 直接断开 |
| 快捷键：⌘T 新建 / ⌘W 关闭 / ⌘1-9 切换 / ⌃⇥ 循环 | ❌ 🔴 | 当前应用没有任何键盘快捷键 |
| 标签状态指示 | ⚠️ 🟡 | `tab-dot` 目前是纯装饰，应反映状态：连接中(黄)/已连接(绿)/已断开(红) |
| 新建标签 `+` 按钮 | ❌ 🟡 | 标签栏末尾放 +，弹出服务器选择 |
| 窗口标题跟随当前会话 | ❌ 🔵 | 如 `root@prod-1 — dssh`，多窗口时可区分 |

## 2. 分屏（panes）

| 功能点 | 状态 | 细节 |
| --- | --- | --- |
| 左右/上下分屏（最多 2 窗格） | ✅ | 再点一次同方向=取消分屏 |
| **关闭单个窗格** | ❌ 🔴 | 目前分屏后**无法单独关闭其中一个窗格**，只能关整个标签。每个窗格需自己的 × 按钮与快捷键 |
| 拖拽调整分屏比例 | ❌ 🟡 | 当前固定 50/50 |
| 快捷键切换窗格焦点 | ❌ 🟡 | 如 ⌥⌘←/→ |
| 新窗格可选不同服务器 | ❌ 🔵 | 当前只能复制同服务器会话；分屏按钮应允许选"连接其他服务器" |
| 超过 2 窗格的任意拆分 | ❌ 🔵 | Tabby 式嵌套分屏，成本高，暂缓 |

## 3. 终端（TerminalView）

| 功能点 | 状态 | 细节 |
| --- | --- | --- |
| 中文输入（IME） | ✅ | 已修 WebView2 contenteditable bug |
| 主题/字号/字体热更新 | ✅ | 逐键赋值绕过 Proxy 限制 |
| Kitty graphics + 双击图片预览 | ✅ | 核心差异化功能 |
| **断线后重连** | ❌ 🔴 | 当前 exit/断开后终端只打印一行黄字就死掉，**必须重启标签**。应在终端内显示 `[已断开] 按 R 或点击此处重连`，重连复用同窗格与滚动缓冲 |
| 断线检测反馈 | ⚠️ 🔴 | 后端有 15s keepalive 防 NAT 断线，但对端真正断开时无主动探测与状态上抛，UI 无感知 |
| 终端内搜索（⌘F） | ❌ 🔴 | 滚动缓冲搜索、高亮全部匹配、Enter/⇧Enter 跳转 |
| 复制即选 / 右键粘贴 | ❌ 🟡 | 设置项：copy-on-select 开关、右键行为（粘贴 or 菜单） |
| 多行粘贴警告 | ❌ 🟡 | 粘贴内容含换行时弹确认（附内容预览），防误执行危险命令；bracketed paste 由终端层保证 |
| 字号快捷键 ⌘+/⌘-/⌘0 | ❌ 🟡 | |
| 清屏快捷键 ⌘K | ❌ 🔵 | |
| 滚动条可视位置 | ❌ 🔵 | 取决于 ghostty-web 能力，待验证 |
| URL 识别点击 | ❌ 🔵 | ⌘+点击打开浏览器 |
| 会话日志落盘 | ❌ 🔵 | 设置开启后按会话存文本日志 |

## 5. 服务器表单（ServerForm）

| 功能点 | 状态 | 细节 |
| --- | --- | --- |
| 名称/分组/地址/端口/用户/认证方式 | ✅ | 密钥进 keyring 不回显 |
| 私钥路径文件选择器 | ❌ 🔴 | 当前手输 `~/.ssh/id_ed25519`，应提供浏览按钮（Tauri dialog）+ 默认扫描 `~/.ssh/` 列出可选密钥 |
| 测试连接按钮 | ❌ 🟡 | 保存前验证可达性与认证，成功/失败即时反馈 |
| 复制现有条目 | ❌ 🟡 | 同构机器（如集群节点）批量录入的刚需 |

| 跳板机 / ProxyJump | ❌ 🟡 | 选择另一台已存服务器作为跳板（链式暂不做） |
| keepalive / 高级项 | ❌ 🔵 | 覆盖默认 15s 间隔；TERM 类型；启动环境变量 |

## 6. SFTP 面板（SftpPanel）

| 功能点 | 状态 | 细节 |
| --- | --- | --- |
| 面包屑导航 / 刷新 / 新建目录 / 下载 / 重命名 / 删除 / 拖拽上传 | ✅ | |
| **上传进度** | ❌ 🔴 | 当前只有"正在上传 n 个文件…"，无单文件进度/速度/剩余时间。后端需进度事件，前端进度条 |
| 传输队列 | ❌ 🟡 | 多个传输排队、可取消；后台继续（面板关闭不中断） |

| 双击编辑远程小文件 | ❌ 🟡 | 下载到临时文件→系统编辑器打开→保存后自动回传（electerm 模式），小于阈值（如 512KB）生效 |
| 路径手动输入跳转 | ❌ 🟡 | 面包屑栏点击可切换为输入框，支持 `~` 与补全 |
| 排序（名称/大小/时间）与隐藏文件开关 | ❌ 🟡 | 点表头排序；`.` 开头文件默认隐藏可切换 |
| 右键菜单 | ❌ 🟡 | 当前右键仅选中。菜单：下载/重命名/删除/复制路径/新建/刷新/属性 |
| 多选（⇧/⌘）批量操作 | ❌ 🔵 | |
| 目录书签 | ❌ 🔵 | 按服务器记忆常用目录（Xterminal 有） |
| 文件属性/权限查看与修改 | ❌ 🔵 | chmod 八进制输入 |
| 双击行为区分 | ⚠️ 🟡 | 当前双击文件=下载，无提示；与"双击编辑"需求冲突，需在设置里选默认行为 |

## 缺陷速览（优先修的 🔴）

1. 分屏后无法关闭单个窗格（§2）
2. 断线后终端死掉，无法原地重连（§3）
3. 标签页不能重命名、无中键/右键/快捷键（§1）
4. 关闭标签/退出应用无确认，误操作直接断会话（§1/§10）
5. 服务器列表单击即连接，易误触（§4）
6. SFTP 上传无进度（§6）
7. 端口转发规则不持久化（§7）
8. 私钥路径手输、无文件选择器（§5）
9. 全应用无键盘快捷键（§10）
