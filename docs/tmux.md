# tmux 支持

连接服务器后，点击终端工具栏的 **tmux** 打开管理面板。

- 发现当前远端用户默认 tmux 服务的会话，每 5 秒刷新。
- 面板顶部“复用已打开的 tmux 标签页”默认开启并记住设置。双击会话优先切换到同一服务器、用户及会话创建时间匹配的已有标签页或分屏；没有匹配项时新建。右键“在新标签页中打开”始终创建新标签页，关闭开关后双击也始终新建。
- 拖动会话到同组的另一个会话上可交换位置，目标卡片显示描边。顺序保存在远端会话的 `@dssh_order` 选项中，其他 SSH 连接刷新后同步；拖到文件夹仍用于移组。
- 会话可直接拖入文件夹（含折叠的文件夹），悬停时高亮目标，松开后保存远端分组并展开目标文件夹。拖入“未分组”可移出分组；文件夹标题横向显示图标和数量，会话缩进显示。
- 右键会话选择“设置分组”，可选择已有分组或输入新分组名称，留空移至“未分组”。列表按分组显示数量，点击组标题折叠或展开。分组保存到远端会话的 `@dssh_group` 选项，同一用户、同一 tmux 服务的不同 SSH 连接刷新后共享；折叠状态仅影响当前面板。空组自动消失，tmux 会话销毁后分组信息不保留。
- 右键会话选择“设置别名”，支持中文，留空可清除。列表优先显示别名并保留原名；别名保存到远端会话的 `@dssh_alias` 选项，同一服务器、同一用户、同一 tmux 服务的不同 SSH 连接会在刷新后看到。SSH 断开或 dssh 重启不会丢失，tmux 会话销毁后不保留；不会修改会话原名。
- 新建或重命名会话，点击“新标签附加”使用独立 SSH 终端进入会话，不强制分离其他客户端。
- 管理窗口与窗格：新建、重命名窗口、切换窗口/窗格、远端左右/上下分屏、放大/还原、进入复制模式。
- “分离 tmux”或关闭附加标签会断开本客户端，远端会话与任务继续运行；“结束”操作会确认后终止相应远端任务。
- 网络断开后按 2、4、8 秒间隔最多自动重试三次；主动分离不会自动重新附加。也可手动重连。会话 ID 和创建时间必须匹配，已销毁的会话不会被自动重新创建。
- 启用鼠标只修改所选会话的运行时选项。图片透传只修改指定窗格的 allow-passthrough，需 tmux 3.3+，且远端应用必须支持 tmux 转义封装；不会写入用户的 .tmux.conf。

当前管理默认 socket，不包括自定义 `-L` / `-S` 服务。重启 dssh 后，可重新连接服务器并在面板发现、附加仍存活的会话。此实现使用常规 tmux PTY 客户端，远端分屏保持在 tmux 中。

附加时不会向已有窗格注入 shell 初始化脚本，因此不会干扰 vim、REPL 等前台程序。tmux 附加终端的目录跟随取决于远端现有 OSC 7 配置。

实现与验证：

- 管理命令走独立 SSH exec 通道，名称进行 shell 转义，操作目标限定到所选会话。
- 终端在监听输出/退出事件后才发送 ssh_start，避免快速附加时首屏丢失。
- 针对 tmux 3.4，结束放大状态的窗口/会话前先还原，避免本机测试中出现的 tmux server 异常退出。
- 已在 WSL Ubuntu 的 tmux 3.4 独立 socket 上验证创建、重命名、窗口切换、分屏、放大及销毁；隔离测试通过后清理测试服务。

参考：[tmux 手册](https://man.openbsd.org/tmux.1)。
