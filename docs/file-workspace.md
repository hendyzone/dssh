# 文件工作区与截图粘贴

## 工具入口
终端右侧竖栏依次是文件、tmux、端口转发；点击展开，再点收起。拖动面板标题到终端左侧或右侧高亮区停靠，图标也随之换边。支持 Alt+方向键调整停靠位置。

## 文件管理
- 默认打开远程用户主目录。顶部路径栏可以直接输入绝对路径并前往。
- “隐藏文件”控制点开头文件的显示；“目录树”切换树与平面列表。三角展开子目录，双击目录将其设为当前目录。
- 筛选只针对当前目录和已展开的子目录，不执行全盘搜索。
- “tmux 工作目录”列出窗格及其目录，选择正在运行 Codex/Claude 的窗格即可定位。不向正在运行的 AI 输入框发送命令。
- 已知 shell 目录时也可使用定位和跟随。tmux 目录由单独查询获取；需要刷新时再次点击工作目录。
- 拖本地文件或文件夹到文件面板，或点击上传选择文件。目标是路径栏所示目录；文件夹递归上传并保留空目录，同名时确认合并文件夹并覆盖文件。暂不支持上传符号链接。
- 双击文件下载并用系统默认应用打开。“打开方式”可选择本地应用程序的完整路径。每次下载使用独立目录，避免不同服务器同名文件相互覆盖。本地应用的修改不会自动回传。
- 文件行悬停显示操作。“在线编辑”支持不超过 1 MB 的 UTF-8 文本。保存时检查远端内容是否变化；存在冲突则拒绝覆盖，并保留输入框中的修改。每次保存前在原文件旁建立权限受限的 .dssh-backup 文件。非 UTF-8、二进制及大文件需下载打开。

## 给 SSH 中的 Codex / Claude 粘贴截图
1. 截图并复制到剪贴板。
2. 点击要输入的远程终端，Ctrl+V / Ctrl+Shift+V，或右键“粘贴截图（上传到远程）”。
3. 客户端上传 PNG 后插入远程绝对路径，不自动回车；补充问题后发送。

支持 20 MB 以内 PNG。图片存于远程用户主目录下独立的 .dssh-image-* 私有目录，使用完成后可在文件树里清理。该功能传递图片文件路径，后续读取图片取决于远程 AI 工具及当前模型的图片能力。上传中切换标签或焦点时不会把路径插到其他终端。

## 克隆连接
连接右键 → 克隆。在原分组生成“原名称 副本”，复制连接配置、转发规则和已保存凭据。凭据由后端复制到新连接的系统凭据库记录，不通过前端明文传递；两条连接的 ID 和转发规则 ID 独立。私钥路径指向原文件。

## 验证范围
