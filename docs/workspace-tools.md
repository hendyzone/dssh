# 工作区工具

右侧工具栏新增任务状态、代码修改和监控。所有工具均可拖动标题左右停靠；底部监控摘要保留。

## 任务状态和提醒
- 自动跟踪已打开终端的输出、断开和工具通知。任务卡片可跳回对应标签与窗格。
- 终端文字中的确认、完成和错误提示属于推测，界面明确标注。15 秒无输出只显示安静状态，不判定任务完成。
- 支持 OSC 9、OSC 777 notify 通知。还支持适配器事件 OSC 777;dssh;running/waiting/done/error;消息，以 BEL 或 ST 结束。当前未自动改写 Codex、Claude、pi 的配置；没有通知的程序使用活动及文本推测。
- 后台重要状态显示应用内提醒。任务面板点击“开启桌面提醒”后使用系统通知；Windows 推荐安装包，系统免打扰可能抑制横幅。通知不包含终端完整内容。

## 代码修改
填写项目绝对路径、使用当前终端目录，或选择 tmux 窗格目录。点击刷新读取 Git 工作区，按未暂存、已暂存、新文件分组。点击文件查看对应差异。
只读展示，不执行提交、回退或暂存。列表包含人工修改，不自动将所有变更归因给 AI。输出超过 2 MB 时停止显示并提示。目录必须位于 Git 仓库内。

## SFTP 和 Markdown
文件树使用统一线性图标与无边框展开箭头；大小、时间通过悬停查看。
下载成功提示、完成传输约 5 秒后收起；失败信息保留。
在线打开 .md/.markdown/.mdown 文件默认渲染预览，可切换编辑源码，未保存内容在两种模式间保留。支持表格、列表、引用和代码块；不执行原始 HTML，图片只显示说明，不自动访问外部地址。

## 验证范围
前端回归、Git 状态解析、Markdown 安全渲染和模拟工作区界面已检查。未连接用户真实服务器执行任务或修改文件。
